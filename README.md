# Alicerce AI Studio

Este projeto foi desenvolvido no **Google AI Studio** e tem como objetivo explorar e demonstrar aplicações de inteligência artificial usando o modelo Gemini.

## 🚀 Funcionalidades
- Criação e execução de prompts personalizados
- Testes de workflows com IA
- Exportação de código para integração em outros projetos

## 📂 Estrutura
- `alicerce GitHub.zip` → Arquivos exportados do AI Studio
- `src/` → Código principal (se aplicável)
- `docs/` → Documentação adicional
